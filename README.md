# 财报三维度分析 Skill

## 📋 简介

这是一个专业的财务分析师 Skill，基于"盈利质量、增长驱动、管理层指引"三维度框架，深度拆解上市公司财报本质。

**版本**: v1.1.0  
**作者**: 代永华 (落天)  
**创建日期**: 2026-05-18

## ✨ 核心功能

- **三维度深度分析**：盈利质量、增长驱动、管理层指引
- **数据交叉验证**：自动从多个权威来源获取并验证财务数据
- **可视化图表**：自动生成过去三年收入和利润趋势图（PNG + HTML）
- **变异视角**：识别市场共识与实际情况的差异
- **投资建议**：提供估值对比和操作触发条件

## 📦 安装方法

### 方法 1：通过 real_cli 本地安装（推荐）

```bash
# 解压 ZIP 文件后，在包含 SKILL.md 的目录执行
real_cli skills install local --json '{"sourcePath": "/path/to/financial-trinity-skill-v2"}'
```

### 方法 2：手动复制

1. 找到已安装的 skills 目录（通常在 `~/.skills/`）
2. 将本目录中的所有文件复制到新的 skill ID 目录下
3. 确保目录结构如下：
   ```
   <skill-id>/
   ├── SKILL.md
   ├── install.sh
   └── README.md
   ```

## 📊 分析方法论

### 维度一：盈利质量（Quality of Earnings）
- GAAP vs Non-GAAP 净利润对比
- 现金流健康度分析
- 收入确认方式评估

### 维度二：增长驱动（Growth Drivers）
- 业务板块分部拆解
- 关键运营指标追踪
- 资本开支去向分析

### 维度三：管理层指引与验证
- 历史承诺兑现情况
- 最新战略指引提取
- 风险披露质量评估

## ⚙️ 依赖要求

- Python 3.9+
- matplotlib（用于生成静态图表）
- plotly（用于生成交互式图表）

运行 `install.sh` 脚本可自动安装依赖：

```bash
bash install.sh
```

## 📝 输出规范

- Markdown 格式报告
- 包含数据表格和可视化图表
- 所有关键数据标注来源
- 提供明确的估值判断和操作建议

## ⚠️ 注意事项

1. 本 Skill 仅适用于**上市公司**财报分析
2. 需要网络连接以获取最新财报数据
3. 不提供明确的投资建议（如"明天就买"），仅提供分析和评级
4. 数据不足时会明确标注并降低结论可靠性
